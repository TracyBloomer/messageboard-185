# MessageBoard

Public onchain short-message board built with Next.js, TypeScript, Tailwind CSS, wagmi, viem, lucide-react, and framer-motion.

## Contract

- Address: `0xb4d1d4285f057e69feef69b1f816da0d890849cb`
- Reads:
  - `getCount()`
  - `messages(uint256)`
- Writes:
  - `post(string content)`

## Local scripts

```bash
npm install
npm run build
npm run dev
```
